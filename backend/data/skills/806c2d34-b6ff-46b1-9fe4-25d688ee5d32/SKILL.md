# 数据清洗和去重技能

## 功能说明
本技能可以对指定数据源中的数据表进行清洗和去重操作，支持多表批量处理。主要功能包括：
- 支持多种数据源（Excel、SQLite、CSV等）
- 基于主键（关键字段）整行去除缺失值数据
- 基于主键（关键字段）整行去除重复数据
- 去除所有列均为空值的整行数据
- 记录详细的处理日志
- 支持多表同时处理
- 当未指定主键时，默认使用数据表的第一列作为主键
- 特别适合处理文物数据等包含空行和重复数据的情况
- 直接在原表上进行修改，不生成新表作为返回参数

## 使用方式
1. 选择目标数据源（如文物数据源）
2. 选择需要清洗的数据表（如"全国文物"数据表）
3. 设置主键列（可选，如不指定则使用第一列作为主键）
4. 运行清洗和去重操作（操作将在原表上直接进行）
5. 查看处理结果和日志

## 脚本说明
- `main.py`: 主处理脚本，负责协调清洗和去重操作
- 基于主键的清洗操作：删除主键列值为空的整行数据，同时删除所有列均为空值的整行数据
- 基于主键的去重操作：删除主键列值重复的整行数据，保留第一次出现的数据
- 主键处理逻辑：当未指定主键时，默认使用数据表的第一列作为主键
- 针对文物数据的处理：特别优化了对文物数据中常见空行和重复数据的处理能力
- 数据处理方式：直接在原表上进行修改，不生成新表作为返回参数

## 参数规范
- `datasource_id`: 数据源ID（必选）
- `table_names`: 数据表名称列表（必选）
- `primary_key`: 主键列名（可选，如不指定则使用第一列作为主键），用于数据清洗和去重的依据
- `cleaning_options`: 清洗选项配置（可选）
  - `remove_empty`: 是否基于主键删除空值记录（默认为true）
  - `remove_all_empty`: 是否删除所有列均为空值的整行数据（默认为true）
  - `deduplicate`: 是否基于主键去重（默认为true）
- `output_log`: 日志输出路径（可选）

## 示例应用
对于文物数据源中的"全国文物"数据表，使用示例：
```yaml
datasource_id: cultural_relics
table_names: ["全国文物"]
primary_key: "文物编号"
cleaning_options:
  remove_empty: true
  remove_all_empty: true
  deduplicate: true
output_log: "./文物数据处理日志.log"
```
注意：本技能直接在原表上进行修改，不会生成新表作为返回参数。

## 常见问题解答
### 文物数据源的全国文物数据，清洗去重后，文件内容没有变化，这是怎么回事？

这种情况可能由以下几个原因导致：

1. **数据本身没有需要清洗的问题**：检查数据表中是否存在空值行或重复行，如果数据本身已经干净，则清洗操作不会改变文件内容。

2. **主键列设置不正确**：确保指定的主键列（如"文物编号"）确实存在且数据有重复。可以使用日志文件确认主键列的选择是否正确。

3. **主键列没有空值或重复值**：检查主键列是否存在空值或重复值。如果没有，则相应的清洗和去重操作不会产生任何变化。

4. **数据表访问权限问题**：确保技能有足够的权限修改目标数据表。

5. **数据源连接问题**：检查数据源连接是否正常，有时候技能可能未能正确读取或写入数据表。

6. **数据格式问题**：某些特殊情况（如主键列是文本类型但实际包含数字）可能导致比较操作失败。

建议查看生成的日志文件，其中会详细记录执行的操作和结果，帮助定位问题所在。如果日志显示执行了操作但无数据变化，通常意味着数据本身已经符合清洗标准。
