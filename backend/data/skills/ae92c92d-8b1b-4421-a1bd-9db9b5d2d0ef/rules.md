### SKILL-DQ-001 提取结果与源文档一致性校验
- 适用范围: 所有提取的表格和正文规则
- 检查逻辑: 数据处理完后，检查提取的规则跟源PDF文档是否一致，重点检查正文的章节数以及表格的行数和列数
- 阈值: 0
- 严重等级: error

### SKILL-DQ-002 表格合并单元格回填校验
- 适用范围: 所有提取的表格
- 检查逻辑: 检查表格的合并单元格是否能对应，检测各列中是否存在孤立空值（前后行有值、中间行为空）或连续空值，这些是合并单元格未回填的信号
- 阈值: 0
- 严重等级: warn

### SKILL-DQ-003 表格子列对应校验
- 适用范围: 含多级表头的表格
- 检查逻辑: 检查某一列的子列是否能对应，检测多级表头子列的数据行中父项值是否完整回填到每个被合并覆盖的行，若子列存在非空值但部分行为空则预警
- 阈值: 0
- 严重等级: warn
