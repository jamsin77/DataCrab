### SKILL-DQ-001 提取的表格数据不得丢失行和列
- 适用字段: 行和列
- 检查逻辑: 提取的表格数据相比源文档不得丢失行和列，表格每一行的列数必须与表头列数一致；如果是提取后的数据已经经过归并，归并过程中不得丢失有效数据；。
- 严重等级: error

### SKILL-DQ-003 垂直合并单元格列必须补全列值
- 适用字段: 表格中垂直合并单元格所在列
- 检查逻辑: 垂直合并单元格所在列中，空值必须用该单元格非空值回填，确保每一行该列都有明确值，不得因合并单元格导致列值缺失。
- 严重等级: error

### SKILL-DQ-004 与表头不一致的子列必须按行拼接
- 适用字段: 多级表头展平不彻底导致的重复列名或子列分解
- 检查逻辑: 某一行的某一列存在与表头不一致的子列时，必须按行把各子列内容用分号拼接，确保不丢失任何子列信息；不得舍弃子列数据或仅保留其中一个子列。
- 严重等级: error

### SKILL-DQ-005 列值必须与表头语义一致
- 适用字段: 所有列
- 检查逻辑: 每一列的值必须与该列表头的语义一致，不得把其他列的值填入错误的列。例如：序号列只填序号，分类列只填分类，名称列只填名称；若某列的值明显属于其他列的语义，判定为列错位。分类列和序号列必须作为独立列分开，不得混在一列，分类列的值不得丢失。
- 严重等级: error
