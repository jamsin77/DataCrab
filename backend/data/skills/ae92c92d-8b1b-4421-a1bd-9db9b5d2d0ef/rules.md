### SKILL-DQ-001 表格名称必须使用文档中的完整全名
- 适用字段: table_name
- 检查逻辑: 每个表格名称必须包含文档中该表格的完整名称（含表号、表名及同一行或相邻行的补充说明）。若仅使用"表1""表2"之类的编号、只取部分表名、或截断补充说明，判定为违规。
- 严重等级: error

### SKILL-DQ-002 表格列数与行数必须保持一致
- 适用字段: 表格数据（每行列数 vs 表头列数）
- 检查逻辑: 表格每一行的列数必须与表头列数一致；缺失列应补空值，多余列内容应合并到该行最后一列（用分号分隔），不得丢弃有效数据，也不得新增列破坏表结构。
- 严重等级: error

### SKILL-DQ-003 有序号表格必须按序号归并为一行
- 适用字段: 序号列（首列为序号或编号）
- 检查逻辑: 若表格存在序号列，相同序号的多个行必须按语义合并为一行；合并单元格的子行不得分配新序号；子序号（如 3.1）应归并到父序号（如 3）；同一序号不得因分页、分行或转置被拆散。
- 严重等级: error

### SKILL-DQ-004 垂直合并单元格列必须补全列值
- 适用字段: 表格中垂直合并单元格所在列
- 检查逻辑: 垂直合并单元格所在列中，空值必须用上方最近非空值回填，确保每一行该列都有明确值，不得因合并单元格导致列值缺失。
- 严重等级: error

### SKILL-DQ-005 与表头不一致的子列必须按行拼接
- 适用字段: 多级表头展平不彻底导致的重复列名或子列分解
- 检查逻辑: 某一行的某一列存在与表头不一致的子列时，必须按行把各子列内容用分号拼接，确保不丢失任何子列信息；不得舍弃子列数据或仅保留其中一个子列。
- 严重等级: error

### SKILL-DQ-006 序号不得丢失
- 适用字段: 含序号列的表格
- 检查逻辑: 修复后的序号集合必须包含修复前的所有序号，不得丢失任何序号。行数可以因归并减少，但序号不能消失
- 阈值: 0
- 严重等级: error
