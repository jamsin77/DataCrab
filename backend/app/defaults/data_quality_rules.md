# 数据质量库（Data Quality Rules Library）

> 规则级数据检查规则。DataInspector 检查时引用 `DQ-xxx` 编号。
> 编辑本文件后保存即可生效；可点击「恢复默认」还原。

## 规则定义说明

每条规则包含：规则ID、维度、适用范围、检查逻辑、阈值、严重等级、修复建议。
维度基于 DAMA-DMBOK 六维度 + ETL 过程质量。
严重等级（从低到高）：
- `info` — 提示性，无需修复
- `warning` — 建议修复，不影响核心流程
- `error` — 必须修复，影响数据准确性或完整性
- `critical` — 严重，数据不可用或影响下游业务
- `fatal` — 致命，数据违反法律法规（如敏感个人信息未脱敏即出境、违反《数据安全法》《个人信息保护法》《网络安全法》等），必须立即阻断流程并上报

## 一、完整性 Completeness

### DQ-COM-001 必填字段空值率
- 适用范围: 字段（指定必填字段）
- 检查逻辑: 字段空值率 ≤ 阈值
- 阈值: 0%（必填字段不允许空值）
- 严重等级: critical
- 修复建议: 补充缺失值或回源补数

### DQ-COM-002 主键非空
- 适用范围: 表主键字段
- 检查逻辑: 主键字段不允许空值
- 阈值: 0
- 严重等级: critical
- 修复建议: 排查 ETL 是否丢失主键或回源补数

### DQ-COM-003 关键字段完整率
- 适用范围: 指定关键字段集合
- 检查逻辑: 全部关键字段均非空的记录占比 ≥ 阈值
- 阈值: 95%
- 严重等级: warning
- 修复建议: 评估缺失影响，必要时补数或降级处理

---

## 二、唯一性 Uniqueness

### DQ-UNI-001 主键唯一
- 适用范围: 表主键
- 检查逻辑: 主键值无重复（count(*) - count(distinct pk) = 0）
- 阈值: 0
- 严重等级: critical
- 修复建议: 去重或修正主键生成逻辑

### DQ-UNI-002 业务键唯一
- 适用范围: 业务键（如订单号、身份证号）
- 检查逻辑: 业务键无重复
- 阈值: 0
- 严重等级: critical
- 修复建议: 排查重复产生原因（重跑、Join 膨胀）

### DQ-UNI-003 去重前后差异
- 适用范围: 表
- 检查逻辑: (总行数 - 去重后行数) / 总行数 ≤ 阈值
- 阈值: 1%
- 严重等级: warning
- 修复建议: 评估重复是否合理，必要时去重

---

## 三、有效性 Validity

### DQ-VAL-001 字段符合数据标准
- 适用范围: 字段
- 检查逻辑: 字段值符合对应数据标准（引用 STD-xxx 正则/校验位）
- 阈值: 不合规率 ≤ 0.1%
- 严重等级: error
- 修复建议: 按对应 STD 标准修正或清洗

### DQ-VAL-002 枚举值合法
- 适用范围: 枚举字段
- 检查逻辑: 字段值在合法枚举集合内
- 阈值: 非法值率 0
- 严重等级: warning
- 修复建议: 映射到标准枚举值

### DQ-VAL-003 数值范围合理
- 适用范围: 数值字段
- 检查逻辑: 字段值在业务定义的 [min, max] 区间
- 严重等级: warning
- 修复建议: 核对业务规则，修正越界值

### DQ-VAL-004 异常值检测
- 适用范围: 数值字段
- 检查逻辑: 基于 3σ 或 IQR 检测异常值
- 阈值: 异常值占比 ≤ 1%
- 严重等级: warning
- 修复建议: 复核异常值，确认为真异常还是录入错误

---

## 四、一致性 Consistency

### DQ-CON-001 跨字段逻辑一致
- 适用范围: 同表跨字段
- 检查逻辑: 字段间逻辑成立（如 age = year(now) - year(birth_date)；end_date ≥ start_date；金额 = 单价 × 数量）
- 严重等级: error
- 修复建议: 核对计算字段，修正不一致记录

### DQ-CON-002 外键参照完整性
- 适用范围: 跨表（事实表→维表）
- 检查逻辑: 事实表外键值在维表中存在
- 阈值: 孤儿率 0
- 严重等级: error
- 修复建议: 补维表数据或清理孤儿记录

### DQ-CON-003 编码一致
- 适用范围: 跨表
- 检查逻辑: 同一业务实体在不同表的编码一致（如性别编码统一为 1/2/0）
- 严重等级: warning
- 修复建议: 建立编码映射表统一处理

---

## 五、准确性 Accuracy

### DQ-ACC-001 与源系统对数
- 适用范围: 跨系统
- 检查逻辑: 目标表关键指标(记录数/金额汇总) 与源系统一致
- 阈值: 偏差 0
- 严重等级: error
- 修复建议: 排查过滤条件、丢失/重复记录、精度问题

### DQ-ACC-002 关键指标偏差
- 适用范围: 指标字段
- 检查逻辑: abs(目标值 - 源值) / 源值 ≤ 阈值
- 阈值: 0.01%
- 严重等级: error
- 修复建议: 排查计算口径、舍入、丢失记录

---

## 六、及时性 Timeliness

### DQ-TIM-001 数据更新延迟
- 适用范围: 表/分区
- 检查逻辑: 最新数据时间距今 ≤ 阈值
- 阈值: 24小时
- 严重等级: warning
- 修复建议: 检查调度任务是否正常执行

### DQ-TIM-002 分区连续性
- 适用范围: 分区表
- 检查逻辑: 分区日期连续无缺失
- 严重等级: warning
- 修复建议: 补跑缺失分区

---

## 七、ETL 过程质量

### DQ-ETL-001 数据量不异常增加
- 适用范围: ETL 任务（源表 → 目标表）
- 检查逻辑: 目标表行数 ≤ 源表行数 × (1 + 阈值)
- 阈值: 5%
- 严重等级: error
- 修复建议: 检查是否产生笛卡尔积、Join 重复、未去重

### DQ-ETL-002 数据量不异常减少
- 适用范围: ETL 任务
- 检查逻辑: 目标表行数 ≥ 源表行数 × (1 - 阈值)
- 阈值: 5%
- 严重等级: error
- 修复建议: 排查过滤条件过严、关联条件错误、丢失记录

### DQ-ETL-003 对数（记录数一致）
- 适用范围: ETL 任务（全量同步）
- 检查逻辑: 源表记录数 == 目标表记录数
- 阈值: 0（必须相等）
- 严重等级: critical
- 修复建议: 排查过滤条件、丢失记录、重复写入

### DQ-ETL-004 对数（金额汇总一致）
- 适用范围: ETL 任务（含金额字段）
- 检查逻辑: abs(sum(源.金额) - sum(目标.金额)) ≤ 阈值
- 阈值: 0.01
- 严重等级: critical
- 修复建议: 排查金额精度、丢失记录、重复累加

### DQ-ETL-005 对数（分组汇总一致）
- 适用范围: ETL 任务（含分组聚合）
- 检查逻辑: 按分组键聚合后，各组记录数/汇总值与源一致
- 阈值: 0
- 严重等级: error
- 修复建议: 排查分组键定义、聚合逻辑

### DQ-ETL-006 检索结果不超总量
- 适用范围: 数据查询/检索
- 检查逻辑: 查询返回行数 ≤ 源表总行数
- 严重等级: error
- 修复建议: 检查 Join 是否笛卡尔积、去重逻辑缺失

### DQ-ETL-007 字段空值率不超阈值
- 适用范围: ETL 后字段
- 检查逻辑: 字段空值率 ≤ 阈值
- 阈值: 10%
- 严重等级: warning
- 修复建议: 排查源字段缺失、关联丢失、转换逻辑错误

### DQ-ETL-008 主键唯一性
- 适用范围: ETL 后目标表
- 检查逻辑: 目标表主键无重复
- 阈值: 0
- 严重等级: error
- 修复建议: 检查 Join 膨胀、去重逻辑、主键生成

### DQ-ETL-009 字段类型一致
- 适用范围: ETL 源→目标
- 检查逻辑: 目标字段类型与定义一致（如金额为数值非字符串）
- 严重等级: warning
- 修复建议: 修正 ETL 类型转换

### DQ-ETL-010 任务执行成功率
- 适用范围: 调度任务
- 检查逻辑: 近 N 次执行成功率 ≥ 阈值
- 阈值: 95%（N=10）
- 严重等级: warning
- 修复建议: 排查失败原因，必要时告警

## 八、业务规则（可扩展）

### DQ-BIZ-001 业务逻辑校验
- 适用范围: 业务字段组合
- 检查逻辑: 业务规则成立（如：订单状态为"已支付"时支付时间必填；退货金额 ≤ 原订单金额）
- 严重等级: error
- 修复建议: 按业务规则修正数据或流程

### DQ-BIZ-002 唯一约束（业务组合键）
- 适用范围: 字段组合
- 检查逻辑: 指定字段组合唯一（如同用户同商品同日仅一条记录）
- 严重等级: error
- 修复建议: 去重或修正业务流程

---

## 九、法律法规合规

### DQ-LEG-001 敏感个人信息违规处理
- 适用范围: 含敏感个人信息的字段（身份证号、银行卡号、生物特征、医疗健康、14岁以下儿童信息等）
- 检查逻辑: 敏感个人信息是否未经脱敏即存储、传输或向境外提供
- 法律依据: 《个人信息保护法》第28-29条、《数据安全法》第31条、《网络安全法》第42条
- 严重等级: fatal
- 修复建议: 立即阻断数据流程，对敏感字段实施脱敏（掩码/哈希/加密），排查数据出境合规性，上报数据安全负责人

### DQ-LEG-002 重要数据违规出境
- 适用范围: 被认定为"重要数据"的数据集
- 检查逻辑: 重要数据是否未经安全评估即向境外提供
- 法律依据: 《数据安全法》第31条、《个人信息保护法》第38-39条
- 严重等级: fatal
- 修复建议: 立即停止数据出境，申报安全评估，完成合规审查后方可放行
